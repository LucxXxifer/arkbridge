# ArkBridge v0.2.6

The v0.2.5 release build stopped before package compilation on all three SDK
targets. `ubuntu-latest` had moved to Ubuntu 26.04, whose `install` command is
provided by uutils. The fixed OpenWrt 24.10.3 SDK only accepts a GNU `install`
version string, so its host prerequisite rejected that runner.

SDK builds now use Ubuntu 24.04 with an explicit GNU coreutils dependency and
an early host-tool check before feed preparation. The SDK prerequisite remains
enabled. The SDK version, architecture matrix and IPK package format are
unchanged; no driver or on-router failover behavior changes in this release.
The Auto-check and confirmed primary IPv4 address-loss fixes from v0.2.5 remain
included. The v0.2.5 tag is preserved.

Regression validation covers the fixed SDK host contract and executes the
workflow preflight against GNU, uutils and unknown version outputs. The full
existing script/panel tests and shell checks remain required. A successful
local check does not replace the three cloud SDK builds or package-artifact
acceptance; those must pass before release publication.
